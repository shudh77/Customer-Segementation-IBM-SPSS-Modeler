Mall Customer Segmentation Using K-Means Clustering

📌 About the Project

This project demonstrates customer segmentation using the K-Means Clustering algorithm in IBM SPSS Modeler. It uses the Mall Customer Dataset to group customers based on their characteristics and shopping behavior.

The objective is to identify different customer segments that can help businesses understand customer patterns, improve marketing strategies, and provide customized advertisements and offers.

🎯 Objectives

- Understand customer segmentation using unsupervised machine learning.
- Implement the K-Means Clustering algorithm in IBM SPSS Modeler.
- Preprocess customer data and remove duplicate records.
- Identify customer groups based on relevant input variables.
- Export customer IDs and their assigned clusters to Excel.

🛠️ Tools and Technologies

- IBM SPSS Modeler
- K-Means Clustering
- Mall Customer Dataset
- Microsoft Excel

⚙️ Workflow

1. Import the Mall Customer Dataset into SPSS Modeler.
2. Identify and remove duplicate records using the Distinct Node.
3. Configure variable measurement levels and roles using the Type Node.
4. Apply the K-Means algorithm to create customer clusters.
5. View the cluster assignments using the Table Node.
6. Filter the output to retain CustomerID and Cluster.
7. Export the final segmentation results to an Excel file.

📊 Expected Outcome

The project generates customer segments by assigning each customer to a cluster. The resulting customer groups can help businesses analyze customer patterns and develop targeted marketing strategies.

💡 Applications

- Customer behavior analysis
- Targeted marketing campaigns
- Personalized offers and advertisements
- Customer group identification
- Data-driven business decision-making
